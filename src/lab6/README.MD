## 2. Описание реализованных типов и контейнеров

### 2.1 Аннотации типов

Класс `TypedCollection` и вспомогательные классы в `demo.py` дополнены аннотациями типов. Аннотированы следующие элементы:

- **Параметры конструктора** — каждый параметр имеет указание типа
- **Возвращаемые значения методов** — каждый метод явно указывает тип возвращаемого значения
- **Атрибуты в __init__** — все внутренние переменные имеют аннотации типов

Преимущества аннотаций типов:
- IDE подсказывает типы параметров при вызове методов
- Код становится самодокументируемым

### 2.2 Generic-класс TypedCollection

TypedCollection — это обобщённая коллекция, которая может хранить элементы любого типа (или типа с ограничением). Она повторяет интерфейс коллекции из лабораторной работы №2.

#### TypeVar и их назначение

| TypeVar | Ограничение | Назначение |
|---------|-------------|------------|
| T | нет (любой тип) | Базовый тип элементов коллекции |
| R | нет (любой тип) | Тип результата в методе map (может отличаться от T) |
| D | Displayable | Только объекты с методом display() |
| S | Scorable | Только объекты с методом score() |

#### Методы коллекции

**__init__()** — Создаёт пустую коллекцию. Возвращает None.

**add(item: T) -> None** — Добавляет элемент в коллекцию.

**remove(item: T) -> None** — Удаляет элемент из коллекции.

**get_all() -> List[T]** — Возвращает копию всех элементов в виде списка.

**sort_by(key_func, reverse) -> TypedCollection[T]** — Сортирует коллекцию по переданной функции-ключу. Возвращает self для цепочек.

**filter_by(predicate) -> TypedCollection[T]** — Фильтрует коллекцию по предикату. Возвращает новую коллекцию.

**apply(func) -> TypedCollection[T]** — Применяет функцию ко всем элементам.

**map_to(transform_func) -> List[R]** — Преобразует коллекцию с помощью map().

**find(predicate) -> Optional[T]** — Находит первый элемент, удовлетворяющий условию.

**filter(predicate) -> List[T]** — Фильтрует коллекцию по предикату, возвращает список.

**map(transform) -> List[R]** — Применяет функцию преобразования к каждому элементу.

**__len__() -> int** — Возвращает количество элементов.

**__getitem__(index) -> T** — Предоставляет доступ к элементу по индексу.

**__iter__() -> Iterator[T]** — Возвращает итератор для перебора элементов.

#### Особенность метода map

Метод map использует второй TypeVar с именем R, что позволяет изменять тип элементов при преобразовании:

- Из TypedCollection[Patient] можно получить list[str] (имена пациентов)
- Из TypedCollection[Patient] можно получить list[float] (температуры)
- Из TypedCollection[Patient] можно получить list[int] (возраста)

### 2.3 Протоколы (структурная типизация)

Для демонстрации концепции структурной типизации созданы два протокола.

**Протокол Displayable** требует наличия метода display() -> str.

**Протокол Scorable** требует наличия метода score() -> float.

Суть структурной типизации:
- Объект соответствует протоколу, если у него есть все необходимые методы
- Явное наследование от протокола не требуется

#### Классы, соответствующие протоколам

**Соответствие Displayable:**
- **MedicalRecord** — медицинская карта (метод display())
- **Prescription** — рецепт (метод display())
- **DisplayablePatient** — адаптер пациента (метод display())

**Соответствие Scorable:**
- **LabResult** — результат анализа (метод score())
- **HealthScore** — оценка здоровья (метод score())
